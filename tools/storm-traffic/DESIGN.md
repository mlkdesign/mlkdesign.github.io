# STORM TRAFFIC

Art direction: supplied STORM TRAFFIC Figma, MAIN and ANIMATION pages. Preserve the dark editorial composition, oversized condensed typography, blue graffiti, transparent graphic layers, and contrasting white vacancy cards.

Tokens: background oklch(0.197 0.002 286); foreground oklch(0.964 0 0); accent oklch(0.648 0.202 250); muted oklch(0.69 0.003 286); border oklch(0.35 0.003 286). Oswald 500–700 display, Montserrat 200–600 body. Spacing 8/16/24/40/64/96. Square buttons and cards, round capsule only. Motion 120/200/600ms, cubic-bezier(.22,1,.36,1). Focus ring blue, 3px with offset.

Interactions: native dialog traps focus, Escape closes and restores trigger. Menu locks document scroll. Vacancy → CV preserves selection. Portfolio demo by explicit owner request: client validates fields and file size/type, then simulates a successful submission without transmitting or storing data. Error and success announced inline. Languages persist in localStorage and update all interface copy. Reduced motion disables parallax, lightning redraw and marquee. Pause control stops decorative continuous animations.

Reference assets and node contexts are in ../.design. Raster assets are local Figma exports; screenshots are visual references only and never implementation backgrounds.
