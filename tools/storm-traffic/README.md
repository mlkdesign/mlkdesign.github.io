# STORM TRAFFIC

Адаптивный портфолио-проект по макету Figma: главная страница и реферальная программа.

## Запуск

Требуется Node.js 22.13+.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

```bash
npm run build
npm start
```

`npm start` запускает собранную версию через локальный Cloudflare Workers runtime. Сборка лежит в `dist/`. Проект использует React, TypeScript и Vinext/Vite; CSS написан без Tailwind.

## Страницы и возможности

- `/` — главная, все разделы макета, вакансии, модальные окна.
- `/referral` — реферальная программа, разные бонусы для вакансий, 4 шага, форма рекомендации.
- RU / EN / UA: переключение интерфейса и сохранение выбора между страницами.
- LIGHTNING 3: отдельные слои оболочки и денег, исходные текстуры молний, генерируемые Canvas-разряды, инерционный magnetic parallax.
- Появление секций, параллакс купюр, выделение преимуществ при прокрутке, бесконечная лента партнеров.
- Полноэкранное мобильное меню, native dialog с управлением фокусом, Escape, блокировка прокрутки.
- `prefers-reduced-motion` и переключатель анимации в подвале.
- Локальные шрифты и WebP-графика, метаданные, sitemap и robots.txt.

## Формы — деморежим

По явному запросу владельца проект предназначен для портфолио. Формы проверяют обязательные поля, e-mail / телефон / Telegram, расширение и размер файла (до 10 МБ). Можно приложить резюме или описать опыт минимум 30 символами. Затем показываются загрузка и успех.

**Данные и резюме никуда не отправляются и не сохраняются.** Обработчик находится в `components/application-form.tsx`. Для боевого приема замените демотаймер запросом `fetch` с `FormData` к собственному API; добавьте серверную валидацию, антиспам и интеграцию с получателем. API и учетные данные в этом проекте не настроены.

## Структура

- `components/storm-site.tsx` — общие компоненты и обе страницы.
- `components/lightning.tsx` — Canvas и магнитное движение капсулы.
- `components/application-form.tsx` — формы и состояния.
- `lib/content.ts` — тексты трех локализаций.
- `lib/assets.json` — локальные пути экспорта Figma.
- `app/globals.css` — адаптивная верстка и анимации.
- `public/assets`, `public/fonts` — локальные ресурсы.
- `DESIGN.md` — визуальные решения.

Графика и контент взяты из предоставленного макета. Даты, вакансии и статистика сохранены как часть портфолио-концепта и не являются актуальным объявлением работодателя.
